# Tsay Stage 2 Numerical Compatibility Amendment v1

Status: authorized before the successful Stage 2 construction rerun

Scope: outcome-free canonical-primitive compatibility gate only

Parent contract: `tsay_feature_research_contract_v1.md`
Provenance commit: `1871dc3eba64e11cb95a2d018d53da6953d764f9`

This addendum does not rewrite the Stage 1 contract or checkpoint. It records the
contract owner's narrow authorization after the first Stage 2 attempt stopped at
the exact canonical-primitive compatibility gate.

The trusted `feature_matrix_gc.parquet` predates commit `1871dc3`, which established
the current deterministic CPU rolling-window implementation and pinned numerical
stack. The legacy artifact must be preserved byte-for-byte and must not be
overwritten or regenerated by Tsay research.

The Stage 2 canonical-primitive gate is amended only as follows:

- `atr_20` continues to require exact row identity, exact null-mask equality, and
  exact `float32` value equality.
- `current_range_over_atr` continues to require exact row identity, exact null-mask
  equality, and exact `float32` value equality.
- `realized_volatility_15` requires exact row identity and exact null-mask equality.
  Its candidate values must be recomputed through the current deterministic CPU
  implementation under the versions pinned in `requirements.txt`. On each finite
  eligible row, the legacy and recomputed `float32` representations may differ by
  no more than one representable `float32` value, measured as integer ULP distance.
- The run must record the `realized_volatility_15` mismatch count, maximum ULP
  distance, maximum absolute difference, parent-contract hash, this amendment's
  hash, a guarded through-2024 legacy-primitive slice hash, new Stage 2 artifact
  hashes, numerical environment versions, and the `1871dc3` provenance explanation.

The legacy file contains mixed partitions. Consistent with the unchanged data boundary,
the run records its filesystem identity without computing a whole-file content hash;
only the physically guarded GC through-2024 primitive slice is content-hashed.

This is not a general numerical tolerance. It does not authorize an epsilon-based
comparison, a relaxed gate for another field, a formula/window/reset change, a copy
from the legacy artifact into constructed features, or any outcome access. A null
mask difference or ULP distance greater than one blocks Stage 2.
