# Top-level project dependencies.

# The numerical stack is pinned to exact versions rather than floors.  The
# feature matrix is a frozen research artefact, and the committed Section 6
# missingness figures have been observed to differ between NumPy builds on
# byte-identical input data, so a floor such as "numpy>=2.0" is not enough to
# make two machines agree.  Reproducing committed results requires these exact
# versions; requirements.lock.txt records the full frozen environment.
